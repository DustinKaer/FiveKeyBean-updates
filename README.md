# 金银岛大发明家

当前版本：1.0.10。

此仓库仅提供程序下载和在线更新信息，不公开软件源代码。

下载发布页中的压缩包，解压后运行“金银岛大发明家.exe”。新包默认关闭断网功能；已有用户在线更新时保留 SendKeys.ini 配置。

已启用经过文件校验的 1.0.10 蓝奏更新包镜像。1.0.10 及以上客户端支持从蓝奏自动下载、校验、替换程序并重启，保留原配置和上一版程序备份。旧客户端需先升级至 1.0.10 才能使用蓝奏下载。检查版本信息仍通过 GitHub。

程序显示版本为 1.0.10，更新协议版本为 6.0.10，以兼容旧版本的版本比较。独立更新资产沿用 FiveKeyBean.exe 文件名，更新器保留本地程序名称。
